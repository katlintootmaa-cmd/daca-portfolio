# Week 1 Team Summary

In week 1 our team practiced basic SQL queries with the UrbanStyle database.

We focused on reading data, filtering rows, sorting results, limiting output, and counting records. The main SQL commands were `SELECT`, `FROM`, `WHERE`, `ORDER BY`, `LIMIT`, `COUNT`, and `DISTINCT`.

As a team, we learned that SQL is useful for asking clear questions from a database. We also learned that before doing deeper analysis, it is important to understand what tables and columns are available.

The main takeaway was that basic SQL gives a strong foundation for all later data analysis work.
