# Workflow Description

This file describes the Week 8 workflow in simple steps.

## Workflow

1. Load the needed data.
2. Clean the data.
3. Combine tables where needed.
4. Calculate weekly, monthly, and customer-level results.
5. Create RFM segments.
6. Create visualizations.
7. Export the results.
8. Check that the outputs make sense.

## Main Idea

The workflow should be repeatable. This means that the same steps can be run again later without manually rebuilding the whole analysis.

## What I Learned

I learned that a clear workflow makes a data project easier to understand, test, and improve.
