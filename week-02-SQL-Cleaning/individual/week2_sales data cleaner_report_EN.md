# Week 2 Individual Report: Sales Data Cleaner

This individual work focused on checking and cleaning sales data.

I looked for common data quality problems, including duplicate rows, missing customer values, incorrect dates, inconsistent text values, and values that could create wrong analysis results.

## What I Did

- Checked the structure of the sales data.
- Looked for duplicate records.
- Checked missing values with `IS NULL`.
- Compared empty values, `NULL`, and numeric values.
- Reviewed text formatting problems.
- Thought about how data problems can affect sales reports.

## What I Learned

I learned that data cleaning should be done carefully. It is not enough to simply change values. First I need to find the problem, understand it, document it, and only then decide how to fix it.

## Summary

This task helped me understand that good analysis starts with trustworthy data.
