# Week 2 Team Summary

In week 2 our team worked on data cleaning with SQL.

We looked for data quality problems such as duplicates, missing values, wrong formats, and values that did not make sense. We used SQL to find problems before making any changes.

The main techniques were:

- checking row counts
- finding duplicates with `GROUP BY` and `HAVING`
- checking `NULL` values
- cleaning text with functions like `TRIM()`, `LOWER()`, and `UPPER()`
- documenting problems before fixing them

The most important lesson was that clean data is needed before reliable analysis. If the data is wrong, the final report can also be wrong.
