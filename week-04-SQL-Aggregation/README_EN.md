# Week 4: SQL Aggregation

Eestikeelne versioon: [README.md](README.md)

This week I learned how to summarize data. When a table has many rows, aggregation helps turn them into clear numbers and summaries.

I used `GROUP BY` together with functions like `COUNT()`, `SUM()`, `AVG()`, `MIN()`, and `MAX()`. With these, I can look at sales by month, city, or category.

I also learned the difference between `WHERE` and `HAVING`. `WHERE` filters rows before grouping, and `HAVING` filters groups after the summary is already created.

I also tried using `WITH` statements, or CTEs. This made more difficult queries easier to read, because I could split the work into smaller steps.

By the end of the week, I understood better how to turn raw data into summaries that can be used for real decisions.
