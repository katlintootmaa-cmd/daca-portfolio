## About Me
I want to make a career change and start working as a data analyst. I build data-driven solutions with SQL, Python Pandas, and Power BI, with a focus on making analysis clear and useful for business decisions.

The purpose of this portfolio is to show my development during the DACA learning project: from SQL and data cleaning to Power BI dashboards, Python analysis, an automated pipeline, and career preparation.

## Goal
To learn data analysis through practical projects and build a professional portfolio that demonstrates technical skills, business thinking, and the ability to present results clearly.

- Power BI: KPI cards, trends, filters, dashboard design, and data storytelling

## Selected Projects

### Power BI Investor View
The UrbanStyle investor dashboard brings together key metrics for sales, growth, categories, and channels. The focus of the work was to create an overview that helps quickly assess whether the company is growing and investment-worthy.

- Folder: [week-05-Visualization-Design/individual](week-05-Visualization-Design/individual)
- Main output: Power BI dashboard and business conclusion
- Key result: 2024 revenue increased by 19.08% compared with 2023

### Tallinn Store Dashboard
A location-based Power BI view of UrbanStyle's Tallinn store. The dashboard combines KPIs, sales trends, product or category views, and a short data story for managers.

- Folder: [week-06-Visualization-Storytelling/individual](week-06-Visualization-Storytelling/individual)
- Main output: Tallinn store dashboard and recommendation for management
- Skill learned: connecting dashboard design with a business narrative

### RFM Customer Segmentation in Python
A Python and Pandas based RFM analysis where my role was data cleaning. After cleaning, the dataset contained 8,950 sales rows and 2,540 unique customers.

- Folder: [week-07-Python-Pandas/individual](week-07-Python-Pandas/individual)
- Team work: [week-07-Python-Pandas/team](week-07-Python-Pandas/team)
- Main finding: the VIP Champions segment generates a large share of revenue, although it is not the largest customer group

### API Pipeline and Result Export
Python modules for processing data, creating visualizations, and saving results. My role was visualization and export: Plotly charts, KPI summaries, and CSV/HTML outputs.

- Folder: [week-08-API-Pipeline/individual](week-08-API-Pipeline/individual)
- Team work: [week-08-API-Pipeline/team](week-08-API-Pipeline/team)
- Main output: reusable export functions and pipeline result files

### Career Preparation
An UrbanStyle data analyst recruitment guide where we analyzed a candidate from the employer's point of view: technical skills, portfolio, CV, LinkedIn, onboarding plan, job offer, and interview.

- Folder: [week-09-Portfolio-Career/team](week-09-Portfolio-Career/team)
- Main lesson: a skill list alone is not enough; a portfolio needs a concrete problem, solution, and result
