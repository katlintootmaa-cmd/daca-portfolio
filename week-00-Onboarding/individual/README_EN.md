# Me as the NotebookLM Setup Person

Estonian version: [README.md](README.md)

## 1) Setup
- I created a new NotebookLM notebook named "UrbanStyle Marketing data"
- I uploaded 4 CORE RAG files (CORE_R1 to R4) and waited for them to process
- I generated an Audio Overview and listened to the first fragment
- I asked the AI questions, for example about character roles and program components
- I shared the notebook link with the team in the communication channel

## 2) Practical and Conceptual Things I Learned

### Using AI Tools
- NotebookLM is a powerful tool for answering questions based on RAG files
- I learned how to upload files and generate an Audio Overview - this was quick and intuitive

### Data Processing and Integration
- RAG files help AI create context-based answers
- The biggest surprise was how accurately AI answered based on the files without adding external data

### Teamwork and Sharing
- I learned how to share links and communicate within the team
- When the Audio Overview took time, I asked questions in parallel - this taught me efficiency

### Problem Solving
- When files did not work, I checked the formats (.md/.txt)
- This developed critical thinking

## 3) General Lessons
- AI can be useful for learning, but it needs high-quality input data
- Our recommendation to Toomas: use NotebookLM more in sessions
