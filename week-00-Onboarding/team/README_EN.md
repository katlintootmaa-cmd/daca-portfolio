# Week 0 Team Work: Onboarding

Estonian version: [README.md](README.md)

## Summary

The team created UrbanStyle's shared workspace: a GitHub repository, Supabase project, NotebookLM knowledge environment, and collaboration rules. The goal was to move from individual tools to a shared team work environment where all members can manage data, documentation, and decisions together.

## Role Distribution

| Role | Team Member | Task |
|------|-------------|------|
| A | Karmo | GitHub repository setup: created the shared repository, README structure, and invited members as collaborators. |
| B | Mari | Supabase setup: created the shared database project and the `team_members` table. |
| C | Kätlin | NotebookLM setup: created the shared AI knowledge environment and added CORE RAG files. |
| D | Ragnar | Team Charter creator: wrote the collaboration rules and documented team agreements. |

## Role Descriptions

- Role A, the GitHub repository setup person, was responsible for giving the team one shared and accessible codebase. The output was a working repository, a proper README, and adding members as collaborators.
- Role B, the Supabase setup person, was responsible for creating the shared database environment. The output was a Supabase project, the `team_members` table, and an initial check that team data was saved.
- Role C, the NotebookLM setup person, was responsible for the team's AI knowledge environment. The output was a shared notebook, added learning materials, and a tested knowledge context through control questions.
- Role D, the Team Charter creator, was responsible for documenting collaboration rules, communication channels, and team agreements. The output was a clear work organization model for the following weeks.
