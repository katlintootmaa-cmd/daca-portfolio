# Nädal 0 tiimitöö: Onboarding

English version: [README_EN.md](README_EN.md)

## Kokkuvõte

Meeskond lõi UrbanStyle'i ühise tööruumi: GitHub repo, Supabase projekti, NotebookLM teadmuskeskkonna ja koostööreeglid. Eesmärk oli liikuda individuaalsetest tööriistadest ühisesse tiimitöö keskkonda, kus kõik liikmed saavad andmeid, dokumentatsiooni ja otsuseid koos hallata.

## Rollijaotus

| Roll | Tiimiliige | Ülesanne |
|------|------------|----------|
| A | Karmo | GitHub repo seadistaja: lõi ühise repository, README struktuuri ja kutsus liikmed collaborator'iteks. |
| B | Mari | Supabase seadistaja: lõi ühise andmebaasiprojekti ja `team_members` tabeli. |
| C | Kätlin | NotebookLM seadistaja: lõi ühise AI teadmuskeskkonna ja lisas CORE RAG failid. |
| D | Ragnar | Team Charter koostaja: vormistas koostööreeglid ja dokumenteeris tiimi kokkulepped. |

## Rollide kirjeldused

- Roll A ehk GitHub repo seadistaja vastutas selle eest, et tiimil oleks üks ühine ja kõigile ligipääsetav koodibaas. Rolli väljund oli töötav repo, korrektne README ja liikmete lisamine collaborator'iteks.
- Roll B ehk Supabase seadistaja vastutas ühise andmebaasikeskkonna loomise eest. Rolli väljund oli Supabase projekt, `team_members` tabel ja esmane kontroll, et tiimi andmed on salvestatud.
- Roll C ehk NotebookLM seadistaja vastutas tiimi AI-teadmuskeskkonna eest. Rolli väljund oli jagatud notebook, lisatud õppematerjalid ja kontrollküsimustega testitud teadmuskontekst.
- Roll D ehk Team Charter koostaja vastutas koostööreeglite, suhtluskanalite ja tiimi kokkulepete dokumenteerimise eest. Rolli väljund oli selge töökorraldus, mille järgi järgmistes nädalates koostööd teha.
