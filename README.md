# DACA Portfoolio -- Kätlin Tootmaa

**Junior Data Analyst** | Tartu, Estonia

English version: [README_EN.md](README_EN.md)

## Minust
Soovin teha karjääripööret ning alustada andmeanalüütikuna. Ehitan andmepõhiseid lahendusi SQL-i, Python Pandase ja Power BI abil ning keskendun sellele, et analüüsi tulemus oleks äriliselt arusaadav ja kasutatav.

Selle portfoolio eesmärk on näidata minu arengut DACA õppeprojekti jooksul: SQL-ist ja andmete puhastamisest kuni Power BI dashboard'ide, Python analüüsi, automatiseeritud pipeline'i ja karjääri ettevalmistuseni.

## Eesmärk
Õppida andmeanalüüsi praktiliste projektide kaudu ning ehitada professionaalne portfoolio, mis näitab tehnilisi oskusi, ärilist mõtlemist ja oskust tulemusi selgelt esitleda.

## Peamised oskused
- SQL: päringud, JOIN-id, agregeerimine ja andmete puhastamine
- Power BI: KPI kaardid, trendid, filtrid, dashboard'i disain ja andmelugu
- Python: Pandas, andmete puhastamine, RFM analüüs, Plotly visualiseerimine
- Automatiseerimine: API-põhine andmetöötlus, moodulid, testid ja tulemuste eksport
- GitHub: projektide dokumenteerimine, README-failid ja portfoolio korrastamine
- Ärianalüüs: järelduste sõnastamine juhtkonna, investori ja värbaja vaate jaoks

## Valitud projektid

### Power BI investorivaade
UrbanStyle'i investori dashboard koondab müügi, kasvu, kategooriate ja kanalite põhinäitajad. Töö fookus oli luua ülevaade, mis aitab kiiresti hinnata, kas ettevõte on kasvav ja investeerimisväärne.

- Kaust: [week-05-Visualization-Design/individual](week-05-Visualization-Design/individual)
- Peamine väljund: Power BI dashboard ja äriline järeldus
- Oluline tulemus: 2024. aasta käive kasvas võrreldes 2023. aastaga 19.08%

### Tallinna kaupluse dashboard
Asukohapõhine Power BI vaade UrbanStyle'i Tallinna kaupluse kohta. Dashboard ühendab KPI-d, müügitrendi, toodete või kategooriate vaate ning juhtidele mõeldud lühikese andmeloo.

- Kaust: [week-06-Visualization-Storytelling/individual](week-06-Visualization-Storytelling/individual)
- Peamine väljund: Tallinna kaupluse dashboard ja soovitus juhtkonnale
- Õpitud oskus: dashboard'i sidumine ärilise narratiiviga

### RFM kliendisegmenteerimine Pythonis
Python ja Pandas põhine RFM analüüs, kus minu roll oli andmete puhastamine. Puhastatud andmestikust jäi alles 8950 müügirida ja 2540 unikaalset klienti.

- Kaust: [week-07-Python-Pandas/individual](week-07-Python-Pandas/individual)
- Tiimitöö: [week-07-Python-Pandas/team](week-07-Python-Pandas/team)
- Peamine leid: VIP Champions segment annab suure osa käibest, kuigi see ei ole kõige suurem kliendigrupp

### API pipeline ja tulemuste eksport
Python moodulid andmete töötlemiseks, visualiseerimiseks ja tulemuste salvestamiseks. Minu roll oli visualiseerimine ja eksport: Plotly graafikud, KPI kokkuvõtted ning CSV/HTML väljundid.

- Kaust: [week-08-API-Pipeline/individual](week-08-API-Pipeline/individual)
- Tiimitöö: [week-08-API-Pipeline/team](week-08-API-Pipeline/team)
- Peamine väljund: korduvkasutatavad ekspordifunktsioonid ja pipeline'i tulemuste failid

### Karjääri ettevalmistus
UrbanStyle'i andmeanalüütiku värbamisjuhend, kus analüüsisime kandidaati tööandja vaatenurgast: tehnilised oskused, portfoolio, CV, LinkedIn, sisseelamisplaan, tööpakkumine ja intervjuu.

- Kaust: [week-09-Portfolio-Career/team](week-09-Portfolio-Career/team)
- Peamine õppetund: oskuste nimekirjast üksi ei piisa, portfoolios peab olema konkreetne probleem, lahendus ja tulemus
