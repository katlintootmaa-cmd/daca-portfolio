# Week 3: SQL JOINs

Eestikeelne versioon: [README.md](README.md)

This week I learned how to combine data from several tables. Before this, I mostly looked at one table at a time, but JOINs help me see a bigger picture.

I practiced using `INNER JOIN` and `LEFT JOIN`. I understood that `INNER JOIN` shows only matching rows from both tables, but `LEFT JOIN` also keeps rows that do not have a match.

This was useful when I wanted to find customers who had no purchases or products that had not been sold.

It was also important for me to learn how to use table aliases, because longer queries can become confusing very quickly.
