## What I Did

This week I practiced SQL JOINs with the UrbanStyle database. I focused on combining data from `sales`, `customers`, and `products`.

## Activities

- Checked that Supabase SQL Editor worked.
- Reviewed how tables are connected with primary keys and foreign keys.
- Practiced `INNER JOIN` to return only matching records.
- Practiced `LEFT JOIN` to keep all rows from the left table.
- Used JOINs to answer business questions about customers, products, and sales.

## What I Learned

I learned that JOINs help create a full picture from separate tables. I also learned that `LEFT JOIN` is useful for finding missing relationships, for example customers who have not bought anything.

## Summary

This work helped me understand how SQL can connect separate data sources and make them useful for analysis.
