# Week 6 Guide: Data Storytelling in Power BI

This guide explains how to turn a Power BI dashboard into a clearer data story.

## Steps

1. Choose one clear business question.
2. Select the most important visuals.
3. Add KPI cards for the main numbers.
4. Add a trend chart if time is important.
5. Add comparison charts for products, stores, or channels.
6. Add annotations to explain important changes.
7. Add a reference line, such as a target or average.
8. Write a short story that explains the result.
9. Add a recommendation for the stakeholder.

## Main Idea

A good dashboard should not only show data. It should help the viewer understand what the data means and what decision it supports.
