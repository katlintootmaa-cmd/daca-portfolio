# Week 5 Guide: Visualization Design With Power BI and Supabase

This guide explains the basic steps for creating a Power BI dashboard from Supabase data.

## Steps

1. Connect Power BI to the UrbanStyle data source.
2. Check that the needed tables are available.
3. Choose the business question for the dashboard.
4. Select the most important KPIs.
5. Choose chart types that match the question.
6. Build a clear layout.
7. Add titles, labels, and simple colors.
8. Check that the dashboard is easy to understand.
9. Add a short business conclusion.

## Main Idea

A dashboard should not start with random charts. It should start with a business question and then choose visuals that help answer that question.
